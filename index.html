About

I am a software developer interested in reproducible data work: pipelines that produce the same output from the same input, tests that freeze their criteria before looking at results, and tools that turn messy public datasets into something a person can actually inspect. My current work is all personal and non-commercial.

Projects

Historical Map Animation Pipeline

Python · GIS data · deterministic rendering

A pipeline that turns historical geographic datasets (administrative boundaries, place names, rivers and terrain from historical atlases) into frame-by-frame map animations. Rendering is fully deterministic — the same script and the same seed produce identical frames — so every output can be reproduced, diffed and quality-checked.

Video Production Pipeline

Python · transcription · asset management

Automation tooling for a case-explainer video channel: collecting source material, transcribing recordings, organising reusable landscape footage with licence records, and checking rendered videos before publication. Built to make a one-person production workflow repeatable.

Data Collection & Validation Tools

Python · SQL · scheduled jobs

Small tools for collecting public datasets on a schedule, validating them against frozen criteria, and generating daily summary reports. The emphasis is on evidence: every reported number can be recomputed from the stored raw data.

Notes

Deterministic beats impressive. For generated media I prefer code-driven rendering over one-off generation: if a result cannot be reproduced exactly, it cannot be reviewed properly.

Freeze the criteria first. In data experiments I write down the pass/fail criteria before collecting the sample. Changing the rules after seeing the results makes every conclusion worthless, however good the numbers look.
